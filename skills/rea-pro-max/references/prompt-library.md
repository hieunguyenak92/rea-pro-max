# Task prompts

Use `node <skill>/scripts/rea-pro-max.mjs prompts --target mv3` (or web/electron) to read focused task examples. The catalog includes36 templates across target families. Templates are not provider implementations or task-success measurements.

Choose a real target, a requested outcome and an available runtime. The bundled static/experiment/verification toolkit supports JavaScript/web/MV3/extractedElectron workflows; other families require appropriate external tools and retain their actual unsupported/unknown boundary. Complete requested implementations through the host agent and receiving repository.
